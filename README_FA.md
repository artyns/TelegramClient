# Telegram Client (TDLib + Kotlin)

این مخزن یک **MVP واقعی و قابل توسعه** برای کلاینت اندروید تلگرام است؛ کلون کامل اپ رسمی نیست.

## امکانات فعلی
- اتصال به TDLib از طریق AAR آماده
- ورود با شماره، کد تأیید و رمز دومرحله‌ای
- نمایش گفتگوهای اصلی
- باز کردن گفت‌وگو و دریافت تاریخچه پیام‌ها
- ارسال پیام متنی
- دریافت پیام جدید در گفت‌وگوی باز

## پیش‌نیاز
- Android Studio با JDK 17
- Android SDK 35
- اینترنت برای دریافت وابستگی‌های Gradle
- API ID و API Hash اختصاصی از https://my.telegram.org

## تنظیم API
1. از `local.properties.example` یک کپی با نام `local.properties` بساز.
2. مقادیر واقعی را وارد کن:
   ```
   TELEGRAM_API_ID=عدد_api_id
   TELEGRAM_API_HASH=رشته_api_hash
   ```
3. این فایل را در Git منتشر نکن. در `.gitignore` قرار دارد.

## Build
پروژه را در Android Studio باز کن و صبر کن Gradle Sync تمام شود.
سپس از منوی Build گزینه **Build APK(s)** را بزن.

یا در محیطی که Gradle نصب است:
```
gradle :app:assembleDebug
```
خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## نکات مهم
- این نسخه برای شروع توسعه است، نه جایگزین کامل Telegram.
- فعلاً ارسال متن و نمایش پیام‌های متنی/نوع پیام در UI پیاده‌سازی شده؛ رسانه، تماس، استیکر، پوش نوتیفیکیشن، جست‌وجو، پوشه‌ها، کانال‌منیجمنت و تنظیمات هنوز اضافه نشده‌اند.
- برای انتشار عمومی، نام و لوگوی مستقل انتخاب کن و الزامات API، حریم خصوصی و مجوزهای TDLib را رعایت کن.
- وابستگی `io.github.tdlib-android` یک بسته آماده جامعه‌محور TDLib است؛ نسخه و کد منبع آن را قبل از انتشار بررسی کن.

## Build ابری با GitHub Actions
می‌توانی سورس را در یک repository قرار بدهی و از تب Actions، workflow با نام **Build Android APK** را اجرا کنی.
برای قرار دادن API credentials در زمان Build، دو Repository Secret با نام‌های `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` بساز.
اگر Secretها تنظیم نشوند، APK ساخته می‌شود اما صفحه تنظیم API را نشان می‌دهد و امکان ورود ندارد.


## طراحی رابط کاربری

- فهرست گفتگوها به‌صورت تخت و سبک
